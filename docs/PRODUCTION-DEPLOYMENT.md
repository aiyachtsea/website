# Production deployment runbook — AIyachts (Sanity + GitHub Pages)

Step-by-step to take the site from the current static build to a live,
Sanity-driven site on a **new Sanity account**. The GitHub side
(`aiyachtsea/website`, custom domain `ai-yachting.com`, Pages = Deploy from a
branch) is already live — these steps only add the Sanity content pipeline.

Naming used throughout (change only if you must):

| Thing | Value |
|---|---|
| Sanity folder | `sanity/` |
| Dataset | `production` (public) |
| API version | `2025-02-19` (pinned) |
| Studio hostname | `aiyachts` → https://aiyachts.sanity.studio/ |
| Schema doc type | `yacht` |
| Webhook event type | `sanity-publish` |
| GitHub repo | `aiyachtsea/website` |

The **project ID** and **org ID** are generated by Sanity when you create the
project — you cannot choose them; you paste the project ID in step 2.

---

## 1. Create the Sanity project

```bash
cd sanity
npm install
npx sanity login          # sign in to the NEW account
npx sanity init --dataset production
```

- Choose **Create new project**, name it `AIyachts`.
- Dataset `production`, visibility **public**.
- Note the **project ID** it prints.

Make sure the dataset is public (the build reads it without a token):

```bash
npx sanity dataset visibility set production public
```

## 2. Point the repo at the project

Edit the repo-root **`sanity.project.json`**:

```json
{
  "projectId": "<your new project id>",
  "dataset": "production",
  "apiVersion": "2025-02-19",
  "studioHost": "aiyachts",
  "useSanity": true
}
```

Set `useSanity` to `true` once you have entered at least one yacht (until then,
leave it `false` and the build uses the built-in static fleet).

## 3. Deploy the Studio

```bash
cd sanity
npm run deploy            # → https://aiyachts.sanity.studio/
```

The hostname comes from `sanity.project.json` (`studioHost`), so it never
prompts. If `aiyachts` is taken globally, change `studioHost` (e.g.
`aiyachts-fleet`) and redeploy.

## 4. Enter the fleet

Open the Studio (deployed URL or `npm run studio` locally at `:3333`).
For each yacht: **Yacht → Create new**, fill Details / Specifications / Photos /
Website, then **Publish**. Keep the **slug** identical to the existing image file
names — the site build looks for `assets/fleet/<slug>.jpg` and gallery frames at
`assets/fleet/gallery/<slug>-800/1600.{jpg,webp}`.

The 14 current yachts and their exact values are in `build/site.mjs`
(`STATIC_FLEET`) — copy them across.

## 5. Wire the publish → rebuild webhook

In Sanity: **Manage → API → Webhooks → Create webhook**.

| Field | Value |
|---|---|
| Name | `Rebuild GitHub Pages` |
| URL | `https://api.github.com/repos/aiyachtsea/website/dispatches` |
| Trigger on | Create, Update, Delete |
| Filter | `_type == "yacht"` |
| Projection | `{ "event_type": "sanity-publish" }` |
| HTTP method | `POST` |
| API version | `2025-02-19` |
| Headers | `Authorization: Bearer <PAT>`  ·  `Accept: application/vnd.github+json` |

`<PAT>` is a GitHub fine-grained token scoped to **`aiyachtsea/website`** with
**Contents: Read and write**. Store it only in the webhook config.

## 6. First publish

Publish any yacht (or in GitHub → Actions → **Build & deploy site** → **Run
workflow**). The Action:

1. Checks out `main`, runs `npm run build` with `USE_SANITY=true`.
2. Regenerates the HTML from Sanity into the repo root.
3. Commits the changes to `main` (`[skip ci]`, so no loop).

GitHub Pages then serves the updated site at `https://ai-yachting.com` within a
minute or two.

## 7. Verify

- https://aiyachts.sanity.studio/ opens and lists the yachts.
- Editing + publishing a yacht triggers the Action (Actions tab shows a run).
- The change appears on https://ai-yachting.com after the run completes.

---

## Rollback / safety

- Set `useSanity: false` in `sanity.project.json` and rebuild to fall back to the
  static fleet at any time.
- The build **never fails** on Sanity errors — it logs a warning and uses the
  static fleet, so a Sanity outage cannot break a deploy.
- To remove a yacht from the site: open it in the Studio, turn off **Show on
  website**, Publish.

## Local commands

```bash
npm run build          # generate the site (uses Sanity when useSanity=true)
npm run studio         # local Studio at http://localhost:3333
npm run studio:deploy  # redeploy the hosted Studio
```
