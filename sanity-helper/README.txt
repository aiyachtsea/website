AIyachts — Sanity data helper
=============================

One folder per yacht (14 total). Each contains:
  - <slug>.jpg   the current site photo — UPLOAD this into the yacht's "Main photo" field
  - details.txt  every field to type into the Sanity Studio, tab by tab

How to use:
  1. Open https://aiyachts.sanity.studio/
  2. Yacht -> Create new
  3. In the Details tab, drag <slug>.jpg into "Main photo"
  4. Copy the rest of the values from details.txt into the matching tabs, then Publish
  5. Keep the Slug EXACTLY as written

This folder is a reference only. Nothing here is deployed or read by the build.
